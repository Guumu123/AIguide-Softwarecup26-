## 1. 技术清单

| 技术 | 版本 | 用途 | 配置 |
|------|------|------|------|
| **PostgreSQL** | 15 | 关系数据: 用户、对话记录、景点、FAQ、数字人配置、游客行为数据 | 标准配置 |
| **Redis** | 7.0+ | 缓存: 热点景点数据、会话状态、API限流、TTS音频URL缓存、路线缓存 | 默认配置 |
| **ChromaDB** | 0.4+ | 向量数据库: 文档向量存储与语义检索 | 持久化目录配置 |
| **SQLite** | Flutter 内置 | APP 本地离线缓存 | 无 |

## 2. 数据库表结构

### 2.1 游客表

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    device_id VARCHAR(64) UNIQUE NOT NULL,
    age INTEGER,
    gender VARCHAR(10),
    group_size INTEGER DEFAULT 1,
    interests TEXT[],              -- ['历史', '自然风光', '佛教文化']
    created_at TIMESTAMP DEFAULT NOW()
);
```

### 2.2 对话记录表（含双通道情感融合）

```sql
CREATE TABLE conversations (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    message TEXT NOT NULL,
    response TEXT NOT NULL,
    message_type VARCHAR(10),
    sentiment VARCHAR(10),
    sentiment_intensity FLOAT,
    voice_sentiment VARCHAR(10),
    text_sentiment VARCHAR(10),
    text_confidence FLOAT,
    created_at TIMESTAMP DEFAULT NOW()
);
```

### 2.3 景点信息表（对接知识库）

```sql
CREATE TABLE attractions (
    id SERIAL PRIMARY KEY,
    attraction_id VARCHAR(20) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    scenic_area VARCHAR(50),
    location TEXT,
    parameters TEXT,
    core_function TEXT,
    cultural_meaning TEXT,
    detailed_intro TEXT,
    highlights TEXT,
    performance_info TEXT,
    notes TEXT,
    estimated_duration FLOAT,
    category VARCHAR(50),
    created_at TIMESTAMP DEFAULT NOW()
);
```

### 2.4 FAQ表（独立维护常见问题及答案）

```sql
CREATE TABLE faq (
    id SERIAL PRIMARY KEY,
    question TEXT NOT NULL,
    answer TEXT NOT NULL,
    category VARCHAR(50),          -- '门票' | '交通' | '餐饮' | '景点' | '其他'
    hit_count INTEGER DEFAULT 0,   -- 命中次数统计
    is_hot BOOLEAN DEFAULT FALSE,  -- 是否为高频问题
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

### 2.5 数字人形象配置表

```sql
CREATE TABLE avatar_presets (
```

## 3. Redis 缓存策略

| 缓存 Key | 内容 | TTL | 说明 |
|----------|------|-----|------|
| `attraction:{id}` | 景点详情 | 1 小时 | 热点景点数据 |
| `session:{user_id}` | 最近 3 轮对话历史 | 30 分钟 | 上下文保持 |
| `tts:{text_hash}` | TTS 音频 URL | 24 小时 | 避免重复合成 |
| `rate_limit:{ip}` | 请求计数 | 1 分钟 | API 限流保护 |
| `route:{user_id}:{hash}` | 推荐路线结果 | 2 小时 | 路线缓存 |
| `insights:daily` | 每日洞察报表 | 6 小时 | 游客洞察缓存 |
| `faq:hot` | 高频FAQ列表 | 1 小时 | 热门问题快速匹配 |
| `avatar:preset:{id}` | 数字人配置方案 | 12 小时 | 形象配置缓存 |

### 3.1 缓存更新策略

```python
# 景点数据更新时，清除缓存
async def invalidate_attraction_cache(attraction_id: str):
    await redis.delete(f"attraction:{attraction_id}")
    await redis.delete("attractions:list")

# FAQ更新时，清除热点缓存
async def invalidate_faq_cache():
    await redis.delete("faq:hot")
    await redis.delete("faq:all")

# 知识库文档更新时，清除相关检索缓存
async def invalidate_kb_cache(doc_id: str):
    await redis.delete(f"kb:doc:{doc_id}")
    # 清除向量检索缓存（使用通配符匹配）
    keys = await redis.keys("retrieve:*")
    if keys:
        await redis.delete(*keys)
```

## 5. 数据导入脚本

### 5.1 景点数据导入

```python
import pandas as pd
from sqlalchemy.ext.asyncio import AsyncSession

async def import_attractions(session: AsyncSession, csv_path: str):
    df = pd.read_csv(csv_path)
    for _, row in df.iterrows():
        attraction = Attraction(
            attraction_id=row['attraction_id'],
            name=row['name'],
            scenic_area=row['scenic_area'],
            location=row['location'],
            parameters=row['parameters'],
            core_function=row['core_function'],
            cultural_meaning=row['cultural_meaning'],
            detailed_intro=row['detailed_intro'],
            highlights=row['highlights'],
            performance_info=row['performance_info'],
            notes=row['notes'],
            estimated_duration=row['estimated_duration'],
            category=row['category']
        )
        session.add(attraction)
    await session.commit()
```

## 6. 数据备份策略

| 数据类型 | 备份频率 | 备份方式 | 保留周期 |
|----------|----------|----------|----------|
| PostgreSQL | 每日凌晨 | pg_dump 全量备份 | 7天 |
| ChromaDB | 每日凌晨 | 目录压缩备份 | 7天 |
| Redis | 实时 | RDB + AOF | 持久化 |
| 上传文档 | 实时 | 对象存储（OSS/COS） | 永久 |
